# 🚀 Evolution of Productivity App: From Fun Prototype to Complex Desktop Suite

> *«А что если сделать прикольную штуку?..»* 

Этот репозиторий — история развития одной простой идеи, которая переросла в масштабный полугодовой проект. Это был долгий и непростой путь: с ошибками, техническими победами, изучением нового стека, попытками вести DevLog в TikTok и, в конечном счете, с продуктовым выгоранием и важными выводами.

**Главная цель проекта:** Создание персонального комплексного инструмента для продуктивности (комбайна), объединяющего заметки, быструю систему запуска приложений/папок/скриптов по горячим клавишам и менеджер задач.

### 🔴 V3 — Масштабирование и ретроспектива (Tauri + SQLite + FSD)

> **Статус:** Разработка заморожена. Проект признан продуктово нежизнеспособным, но стал главным катализатором инженерного и продуктового роста.

Проект v3 планировался как ультимативный комбайн для продуктивности на базе **Tauri, SQLite, React, TypeScript, Redux Toolkit, Sass Modules и FSD-lite**. 
После почти 6 месяцев разработки проект был остановлен. Причина — накопленный технический долг, раздутый Scope, ошибки в архитектуре БД и продуктовое выгорание. Однако именно этот «неудачный» проект дал мне колоссальный опыт, который невозможно получить на учебных курсах.
